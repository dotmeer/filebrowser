# Направления развития

Идеи для отдельного обсуждения, без обязательств по срокам и реализации.

- **Пользователи и права доступа:** администратор, обычные пользователи,
  разрешения на действия и каталоги; read-only корни — часть этой модели.
- **Поддержка symlink:** только с отдельно спроектированной моделью безопасности.

Видео/аудиопредпросмотр, корзина и pause/resume не планируются.
Текущие границы продукта — в [SPEC](SPEC.md#3-границы-продукта).
