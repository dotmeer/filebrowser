# I04 — ручной чеклист UI

Проверка выполнена 2026-10-31 в локальном браузере с временными корнем и
конфигурацией (`root=demo`). В рабочие пользовательские каталоги данные не
записывались.

## Проверено вручную

- [x] Прямая ссылка `/browse?root=demo&path=Демо-папка` открывает нужный
  каталог и показывает файл в таблице.
- [x] Дерево изначально показывает только настроенный корень. После раскрытия
  корня появился непосредственный подкаталог `Демо-папка` и его потомок
  `Вложенный`; `Глубже` появился только после отдельного раскрытия `Вложенный`.
  Полного рекурсивного обхода при открытии дерева нет.
- [x] Нажатие checkbox строки увеличивает счётчик выбранных объектов.
- [x] Кнопка «Обновить» перечитывает каталог и сбрасывает выделение.
- [x] Breadcrumb возвращает к корню; браузерные «назад» и «вперёд» восстанавливают
  URL и соответствующее содержимое.
- [x] Страница «Настройки» сообщает о редактировании `config.yaml` на сервере.
- [x] На узком окне страницы остаются читаемыми; широкая таблица прокручивается
  горизонтально.

## Проверено автоматическими тестами

- [x] SSR `/browse` отображает каталог, переданный в URL.
- [x] Пустой каталог отображает отдельное состояние.
- [x] Ошибка отсутствующего каталога показывает безопасное сообщение без
  физического пути и кнопку возврата к корню.
- [x] `/settings` отображает инструкцию про `config.yaml`.

## Не проверено вручную

- [ ] Пустое состояние и ошибка недоступного/исчезнувшего каталога в браузере;
  соответствующие состояния проверены WebApplicationFactory.
- [ ] Linux-контейнер и мобильные размеры вне текущего узкого окна браузера.
