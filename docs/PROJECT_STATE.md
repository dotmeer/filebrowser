# Состояние проекта

Обновлено: 2026-11-13.

## Текущее состояние

Реализованы просмотр и поиск, виртуальный корень AllRoots, создание папок,
переименование, фоновые copy/move/delete, отмена и история в SQLite,
скачивание файлов и ZIP, предпросмотр, загрузка файлов, EN/RU, темы,
Docker и OpenTelemetry. Задание по ревью — [CODE_REVIEW_TASKS.md](CODE_REVIEW_TASKS.md).

Отмена upload связана с задачей по `uploadId`. Одинаковый id не допускает
двух владельцев. Приём через PipeReader корректно прерывается даже при
остановившем передачу клиенте; при потере раннего HTTP-ответа окно загрузки
сверяет итог с SQLite через Blazor. Обычный обрыв не считается отменой.

Общий механизм синхронизации отмены и публикации не допускает конечный файл,
если отмена принята первой. После публикации результат элемента, итог задачи
и снятие регистрации артефакта фиксируются одной короткой SQLite-транзакцией.
При ошибке финализации опубликованный файл сохраняется; регистрация артефакта
остаётся, выполняется попытка зафиксировать failed. При продолжающейся
недоступности БД активная задача будет прервана при следующем запуске.

  хосте отдельно повторены оба Kestrel-теста — **2/2**.

  `dotnet test` — **388/388**, без пропусков. Проект скопирован из read-only
  mount в `/tmp/work`, без `.git`, `bin`, `obj`, `TestResults`;
  `DOTNET_CLI_HOME=/tmp`, `NUGET_PACKAGES=/tmp/nuget`.
- Регрессии: отмена до/после публикации, ошибка SQLite через реальный trigger,
  остановившееся тело запроса и disconnect на настоящем Kestrel.

  8 МиБ через окно загрузки и панель задач; UI/SQLite согласованы, файлов и
  регистраций артефактов не осталось. Закрытие вкладки — failed/upload_aborted.
- `docker build -t filemanager-review .`, `docker compose config --quiet`,
  `git diff --check`, `git diff --cached --check` — успешно.
