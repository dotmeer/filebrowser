## Принятые решения

| ID | Решение | Причина |
|---|---|---|
| D001 | .NET 10, Blazor Interactive Server | Единый серверный стек |
| D002 | Без отдельного TasksHub | Blazor уже поддерживает серверные обновления UI |
| D003 | root + относительный path | Единый публичный контракт без физических путей |
| D004 | Symlink не поддерживаются в MVP | Снижение сложности и рисков |
| D005 | Нет перезаписи данных | Предсказуемое безопасное поведение |
| D006 | SQLite на локальном диске, один экземпляр приложения | Предсказуемая работа хранения |
| D007 | Незавершённые задачи после рестарта interrupted | Без опасного автоматического повтора |
| D008 | Изменяющие HTTP-запросы защищены antiforgery | Анонимный доступ не отменяет CSRF-риски |
| D009 | Конфликт имени — всегда ошибка 409/name_conflict, без автосуффиксов | Не дать напортачить; политика предсказуема |
| D010 | Массовое удаление запрещено, удаляется один объект | Безопасность, меньше риска |
| D011 | Upload не входит в MVP, отложен в roadmap | Уменьшение объёма MVP |
| D012 | ZIP/скачивание папок и наборов не входит в MVP | Уменьшение объёма MVP |
| D013 | Copy/move между корнями разрешены; очередь FIFO | Основной сценарий нескольких корней |
| D014 | Недоступный корень не останавливает запуск | Устойчивость к неподключённым mount'ам |
| D015 | Повреждённая/недоступная SQLite останавливает запуск; автовосстановления нет | Задачи без надёжного хранилища небезопасны |
| D016 | Очистка истории: удаляются только неактивные задачи, вместе с результатом | Контролируемая история без воздействия на файлы |
| D017 | Повторный запуск задач отсутствует | Пользователь сам разруливает последствия |
| D018 | Результат задач — агрегированный по верхнеуровневым объектам | Достаточно для UI, мало записей в БД |
| D019 | Двухфазная модель: предпроверка (все ошибки) + выполнение до первой ошибки | Полный список проблем до старта, без лишних действий |
| D020 | Порядок источников — ordinal-сортировка по публичному пути | Детерминированно, без локаль-зависимости |
| D021 | Copy/move: целевой каталог любой; выбранные объекты кладутся напрямую | Предсказуемое размещение |
| D022 | Скрытые файлы показываются и доступны | Полное соответствие реальному содержимому |
| D023 | Размер — только для файлов, «—» для каталогов; даты UTC | Скорость листинга, единый формат |
| D024 | Переподключение: состояние полностью перечитывается из SQLite | SQLite — источник истины |
| D025 | Прогресс в SQLite не чаще 1 р/с; переходы состояний — сразу | Баланс нагрузки и свежести |
| D026 | OTLP экспорт — опционален; подключение к внешнему Collector через OTEL_* | У пользователя уже развёрнут OTEL-стек |
| D027 | Roadmap — список направлений без порядка и сроков | Каждое направление проектируется отдельно |
| D028 | Решение в формате .slnx (`dotmeer.filebrowser.slnx`) | Формат из структуры репозитория SPEC §20 |
| D029 | Демо-страницы шаблона Blazor удалены (Weather и ссылка в меню); Counter оставлен | Каркас без демо-заглушек; Counter проверяет интерактивный рендеринг |
| D030 | `/healthz` в I01 всегда 200; 503 появится с введением критичных зависимостей (например SQLite) | На этапе каркаса внешних зависимостей нет |

При изменении решения:
- не удалять историю;
- добавить новое решение со ссылкой на заменённое;
- обновить SPEC при изменении требований.
