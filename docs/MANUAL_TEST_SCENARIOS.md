# Ручные проверки

Проверяйте на временных данных. Этот файл — сценарии, а не отчёт об их
прохождении. Результаты и недоступные среды фиксируйте в PROJECT_STATE.
`dotnet test` не заменяет интерактивный браузер и Linux-проверки.

## Развёртывание

- [ ] Compose запускается с обычным UID/GID; процесс приложения не root,
  конфигурация читается, БД сохраняется после пересоздания контейнера.
- [ ] `/health/live` и `/health/ready` → 200 Healthy; главная страница,
  `/_framework/blazor.web.js`, WebSocket/circuit и действия UI работают.
- [ ] Недоступный корень не мешает остальным; восстановление каталога
  и обновление UI возвращают доступ без перезапуска.
- [ ] Невалидный YAML и повреждённая тестовая БД останавливают запуск.
- [ ] Тестовая конфигурация с корнем, содержащим конфигурацию/БД, запускается;
  файлы видны. Удаление защищённых файлов/их родителя отклоняется.
  Не выполняйте разрушительные проверки на реальной БД или системных файлах.
- [ ] JSON-логи содержат traceId ошибки скачивания, не содержат данных файла.
- [ ] При заданном OTLP endpoint Collector получает spans и метрики;
  без exporter приложение также работает.

## Навигация и настройки

- [ ] Дерево загружается лениво; breadcrumbs, прямые ссылки и назад/вперёд
  открывают правильную папку. `/browse` → 404.
- [ ] Оба разделителя меняют ширину панелей; в узком окне действия остаются
  доступны. Длинные имена имеют tooltip, даты — в часовом поясе браузера.
- [ ] Пустой/исчезнувший/недоступный каталог показывает понятное состояние.
- [ ] Выбор одного/нескольких объектов корректно включает действия.
- [ ] Меню открывает настройки и закрывается кликом вне него. «✕» из
  настроек всегда ведёт на `/`, включая прямое открытие `/settings`.
- [ ] Системная/светлая/тёмная тема применяется сразу и сохраняется после reload.
- [ ] EN/RU применяется после сохранения и полной перезагрузки, включая
  диалоги/ошибки; после reload второго браузера язык тот же.
- [ ] AllRoots показывает корни, включая недоступные. Верхний уровень
  запрещает изменения; внутри реального корня обычные действия доступны.

## Поиск и задачи

- [ ] Поиск по подстроке работает в папке и AllRoots; показаны путь результата,
  усечение и недоступные корни. Файл открывает родителя с подсветкой.
- [ ] Во время долгого поиска UI реагирует; новый запрос/выход из поиска
  не позволяет старому результату заменить текущий.
- [ ] Copy/move одного и нескольких объектов создают карточки без refresh;
  видны scanning, прогресс, скорость и финал. Листинг обновляется после работы.
- [ ] Выбор назначения исключает текущую папку, источник и его потомков.
  Конфликт не изменяет существующий файл.
- [ ] Отмена queued/scanning/running не откатывает завершённые объекты,
  не публикует частичные; временные артефакты убираются или остаются
  зарегистрированными при невозможности очистки.
- [ ] После ухода со страницы/возврата и reconnect задачи перечитываются;
  после рестарта активные задачи interrupted, зарегистрированные остатки очищены.
- [ ] Очистка истории требует подтверждения, сохраняет активные задачи,
  не меняет файлы и не теряет регистрацию ещё не очищенных артефактов.

## Удаление

- [ ] Один/несколько объектов удаляются только после checkbox подтверждения;
  задача и результат видны в панели, список файлов обновляется.
- [ ] При symlink/спецфайле/ReadOnly/защищённом файле в любом источнике
  предпроверка отказывает всей пачке, данные остаются.
- [ ] Отмена между объектами сохраняет оставшиеся; после атомарного rename
  текущий объект заканчивает удаление. Ошибка cleanup видна как delete_incomplete.

## Скачивание и предпросмотр

- [ ] Один файл скачивается напрямую; Range возвращает нужные байты.
  Папка/набор — ZIP без смены страницы файлового менеджера.
- [ ] ZIP содержит выбранные данные, пустые каталоги, UTF-8 имена;
  содержимое одной выбранной папки лежит в корне архива, записи store.
- [ ] Один корень из AllRoots скачивается как `<корень>.zip`, несколько —
  недоступны. Архив внутри AllRoots работает как в реальном корне.
- [ ] ZIP: application/zip, attachment, нет Content-Length/Range;
  HTTP/1.1 использует chunked. Повторный тикет работает до 120 с, затем 410.
- [ ] Symlink/спецфайл/заранее нечитаемый файл отклоняется до ответа;
  исчезновение файла после начала передачи обрывает скачивание.
- [ ] Изображения/PDF/текст открываются в модальном окне; Escape/закрытие
  работают. SVG/HTML не исполняются и не поддерживаются предпросмотром.
- [ ] Текст длиннее 512 КиБ усечён с уведомлением. Большой текст не обрывает
  circuit и не передаётся через JS interop в .NET. Быстрое открытие разных
  файлов не смешивает содержимое; текст с HTML показывается буквально.

## Загрузка

- [ ] Кнопка и drag-and-drop загружают пустые/обычные файлы и UTF-8 имена;
  содержимое совпадает побайтово. Папки не загружаются как файлы.
- [ ] В поиске/списке корней загрузка недоступна, внутри AllRoots работает.
- [ ] При выборе более двух файлов и переходе в другую папку вся очередь
  остаётся привязана к исходной папке, включая смену пути между check и POST.
- [ ] Конфликт и превышение лимита показываются до отправки большого тела;
  существующие данные не меняются. Файл 64 МБ проходит при достаточном лимите.
- [ ] Отмена из окна загрузки и из панели задач согласованно даёт cancelled;
  обрыв без пользовательской отмены — failed/upload_aborted.
- [ ] При рестарте загрузка interrupted, остаток очищен; при ошибке/отмене
  до публикации нет конечного файла и незарегистрированного остатка.
- [ ] POST без CSRF → 400, без Content-Length → 411;
  check: свободное имя → 204, конфликт → 409, превышение → 413.
- [ ] Загрузка, прогресс, скорость, ошибки и история локализованы EN/RU.

## Linux и конкурентные операции

- [ ] Обычный UID: права на чтение/запись и отказ доступа дают безопасные ошибки.
- [ ] FIFO, Unix socket и доступный специальный файл отклоняются без зависания
  скачиванием/предпросмотром/копированием/ZIP/удалением, поиск их пропускает.
- [ ] Межтомовый move проверен на разных mounts, источник удаляется только
  после публикации. Опрос свободного места относится к фактическому назначению.
- [ ] Конкурентное создание/публикация одного имени не перезаписывает данные;
  создание папки внешним процессом не превращается в ложный успех mkdir.
