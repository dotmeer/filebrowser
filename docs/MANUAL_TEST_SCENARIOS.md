# Ручные тест-сценарии

Сценарии, которые нельзя полностью покрыть автоматическими тестами:
приёмка развёртывания на реальной среде и интерактивный браузерный UI
с WebSocket-сессией Blazor.

Автоматический suite проходит командой `dotnet test`; он не заменяет
проверки ниже.

## Приёмка развёртывания

Выполнить после развёртывания на новой среде (контейнер или локальный
запуск, тестовые каталоги, не пользовательские данные):

- [ ] `GET /health/live` и `GET /health/ready` → `200` с телом `Healthy`;
- [ ] Конфигурация с корнем `/` запускается на тестовой среде:
      `/health/live` → `200`, разрушительные операции с системными файлами
      не выполняются;
- [ ] Конфигурация, где корень совпадает с каталогом `ConfigPath`,
      запускается; SQLite создаётся рядом с `config.yaml`, оба файла
      видны в листинге как обычные объекты;
- [ ] Открыть `/`: ленивое дерево, список каталога, breadcrumbs,
      прямой URL `/?root=...&path=...`; старый `/browse` отдаёт 404;
- [ ] Раскладка «Каталоги | Файлы | Задачи»: перетаскивание обоих
      разделителей меняет ширину панелей, панели не сжимаются меньше
      минимальных (кнопки и названия не обрезаются);
- [ ] Бургер-меню в правом верхнем углу: пункт «Настройки» открывает
      `/settings`, меню закрывается кликом вне него;
- [ ] На `/settings` переключение «Системная / Светлая / Тёмная» сразу
      меняет оформление; выбор сохраняется после reload; «Системная»
      следует теме ОС; страница `config.yaml` в тёмной теме читаема;
- [ ] На `/settings` выбор «Русский» и сохранение переводит весь интерфейс
      (включая `/`, панель задач и диалоги) на русский после
      перезагрузки; ошибки скачивания (`title`/`detail`
      ProblemDetails `GET /api/fs/download`) также на русском; выбор
      «English» возвращает английский; язык одинаков в другом браузере
      (серверная настройка);
- [ ] Кнопка «✕» (закрыть настройки) на `/settings` возвращает на `/`
      в любом случае — и при переходе из приложения, и при прямом
      открытии `/settings` без истории;
- [ ] Кнопки действий: «Обновить» первая, доступные контрастные,
      недоступные бледные; «Удалить» красная; при узкой панели кнопки
      переносятся на новую строку, не вылезая за границы;
- [ ] Создать папку, переименовать её, удалить с подтверждением;
      повторное создание существующего имени завершается ошибкой,
      данные не перезаписаны;
- [ ] Выбрать ровно один файл и скачать его; проверить Range через
      `curl -H "Range: bytes=0-4" http://127.0.0.1:8080/api/fs/download?...`
      → `206 Partial Content`;
- [ ] Скопировать и переместить один и несколько объектов; проверить
      активные задачи, прогресс, скорость и счётчики; конфликт имён
      даёт ошибку задачи без перезаписи данных;
- [ ] Перезапустить приложение: активные задачи стали `interrupted`,
      после повторного открытия `/` состояние перечитано
      из SQLite;
- [ ] Очистить историю: активные задачи и файлы не изменились;
- [ ] Проверить UID процесса в контейнере:
      `docker exec <container> id -u` → не root (1654 по умолчанию);
- [ ] Логи контейнера в JSON; `traceId` из ProblemDetails ошибки скачивания
      найден в логах;
- [ ] При заданном `OTEL_EXPORTER_OTLP_ENDPOINT`: в Collector видны
      service `dotmeer.filebrowser`, span `filebrowser.task.execute`
      и метрики `dotmeer.filebrowser.tasks.*`.

## Предпросмотр (I28)

- [ ] Двойной клик по файлу изображения (png/jpg/gif/webp/bmp/ico)
      открывает модальное окно с картинкой; окно закрывается кнопкой
      «✕», кликом по фону и клавишей ESC;
- [ ] Контекстное меню файла изображения/PDF/текста содержит пункт
      «Предпросмотр» (EN) / «Предпросмотр» (RU); для неподдерживаемого
      типа (например, `.zip`) пункта нет;
- [ ] PDF открывается в iframe внутри модалки, прокручивается
      (браузер запрашивает Range-фрагменты: `206` в логах/сети);
- [ ] Текстовый файл (txt/md/log/json и т.п.) показывается в `<pre>`
      как текст (в т.ч. содержимое с HTML-разметкой — не исполняется);
      файл больше 512 КиБ показывает уведомление «Показано только
      начало файла» (EN/RU) и заголовок `X-Preview-Truncated: true`
      у ответа `/api/fs/preview`;
- [ ] Кнопка «Скачать» внутри модалки скачивает тот же файл
      (обычный `attachment`-ответ `/api/fs/download`);
- [ ] Прямой запрос `/api/fs/preview?root=files&path=archive.zip`
      → `415` с `code=preview_not_supported` (ProblemDetails, язык
      title/detail соответствует серверной настройке языка);
- [ ] Предпросмотр работает внутри виртуального корня
      (`root=AllRoots&path=<realRoot>/<file>`); под не-ASCII именем
      файла Content-Disposition содержит `filename*=UTF-8''...`;
- [ ] SVG/HTML не предпросматриваются: пункта меню нет, прямой запрос
      → `415`;
- [ ] Язык интерфейса: подписи модалки («Закрыть предпросмотр»,
      «Скачать», «Загрузка предпросмотра…») локализуются EN/RU.

## Удаление (I29)

- [ ] Выделение 2–3 объектов включает кнопку «Удалить»; диалог
      показывает «Удалить выбранные объекты (N)?» и список имён (первые
      пять, затем «и ещё K»);
- [ ] Подтверждение требует чекбокса; после подтверждения диалог
      закрывается, в панели задач появляется задача «Удаление» с
      прогрессом по объектам (строка «Байты» не показывается);
- [ ] После завершения задачи объекты исчезают из листинга, скрытых
      объектов `.filebrowser-*` в папке нет, имена можно занять заново;
- [ ] Удаление каталога с содержимым: каталог исчезает, задача
      завершается `completed`; при перезагрузке страницы листинг
      не показывает остатков;
- [ ] Контекстное меню «Удалить» на одном объекте создаёт задачу
      удаления ровно с одним объектом;
- [ ] Файл с атрибутом «только чтение» (Windows): задача `failed`,
      объект на месте, ошибка «Объект доступен только для чтения»;
- [ ] Попытка удалить папку, содержащую `app.db` или `config.yaml`
      (корень, пересекающийся с `/config`): задача `failed` с ошибкой
      о служебных файлах, данные на месте;
- [ ] Отмена задачи удаления на этапе проверки или выполнения: задача
      `cancelled`, уже удалённые объекты не откатываются, оставшиеся
      «Не обработан»; скрытых `.filebrowser-*` в папке не остаётся;
- [ ] В виртуальном корне «Все корни» кнопка «Удалить» недоступна;
      в результатах поиска удаление недоступно;
- [ ] Панель задач: история хранит задачи удаления после перезагрузки
      страницы и переподключения circuit.

## Скачивание архивом (I30)

- [ ] Кнопка «Скачать ZIP» неактивна без выделения; при выделении
      папки или набора объектов она включает скачивание одного архива;
- [ ] Архив папки содержит её содержимое относительно самой папки
      (без лишних уровней пути), пустые каталоги присутствуют
      отдельными записями (`empty/`), служебных `.filebrowser-*` нет;
- [ ] Выбор из нескольких объектов скачивает только их, структура
      та же, что при скачивании папки;
- [ ] Имя файла архива — `<папка>.zip` (для корня — `<корень>.zip`);
      при выборе ровно одной папки её содержимое лежит в корне архива
      без лишнего уровня; не-ASCII имена записей и содержимое
      читаются после распаковки;
- [ ] Ответ `/api/fs/zip` имеет `application/zip`, `Content-Disposition:
      attachment`, `Transfer-Encoding: chunked`, без `Content-Length`
      и без Range; записи сохранены без сжатия (`compressed == length`);
- [ ] Скачивание не заменяет страницу файлового менеджера: адрес и
      список остаются, появляется файл загрузки;
- [ ] Папка с symlink внутри: скачивание не начинается, в интерфейсе
      показывается ошибка о символических ссылках, страница не
      заменяется JSON-документом;
- [ ] В узле «Все корни» (список корней) выделение одного корня включает
      «Скачать ZIP» → скачивается `<корень>.zip` с содержимым корня;
      выделение двух корней оставляет кнопку недоступной с подсказкой
      «Нельзя скачать все корни одним архивом»; прямой запрос с тикетом
      на `AllRoots` с двумя корнями → `400 invalid_request`;
- [ ] Внутри реального корня, открытого через «Все корни»
      (`?root=AllRoots&path=<корень>/<папка>`), архив работает:
      имя `<папка>.zip`, структура как при работе из реального корня;
- [ ] Повторное скачивание того же выбора в пределах 120 с работает
      (тикет переиспользуемый), после истечения TTL — `410
      ticket_expired`;
- [ ] Язык интерфейса: подписи «Скачать ZIP» / «Подготовка архива…»
      и сообщения об ошибках локализуются EN/RU.
